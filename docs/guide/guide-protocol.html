The conversation

대화

After the socket opens, send exactly three text frames:

소켓이 열리면 정확히 세 개의 텍스트 프레임을 보냅니다:

{"session_id": "qwen3_20260614125444"}
[{"role": "user", "content": "Hi"}, {"role": "assistant", "content": "Hello!"}]
What is the weather in Daejeon today?

Then read text frames until <EOS>. Plain frames are answer text. Three kinds of frame are special:

그다음 <EOS> 까지 텍스트 프레임을 읽습니다. 일반 프레임은 답변 텍스트이고, 세 종류가 특별합니다:

Frame프레임Meaning의미
<think> / </think>Reasoning starts / ends; frames between are the model's thoughts추론 시작 / 끝. 사이의 프레임은 모델의 생각
<tool_call>…</tool_call>A JSON tool record (below)JSON 도구 레코드 (아래)
<EOS>The answer is complete; the server closes the socket답변 완료. 서버가 소켓을 닫음

Tool records

도구 레코드

{"call":   {"id": "call_20250614125444", "function": {"name": "get_weather", "arguments": {"location": "Daejeon"}}}}
{"result": {"id": "call_20250614125444", "function": {"name": "get_weather", "content": "<cached_result:call_20250614125444>"}}}
{"history": [ {"role": "assistant", "content": "", "tool_calls": [ … ]}, {"role": "tool", "tool_call_id": "…", "content": "<cached_result:…>"} ]}

Append the history messages to your own history and send them back next turn. The server keeps the real tool output; the client only sees the <cached_result:…> placeholder.

history 메시지를 내 기록에 붙여 다음 턴에 다시 보냅니다. 실제 도구 출력은 서버가 들고 있고, 클라이언트는 <cached_result:…> 자리표시자만 봅니다.

Errors

오류

  • Unknown session on the socket: closed with code 1008.
  • 소켓에서 모르는 세션: 코드 1008 로 닫힘.
  • Known defects: session errors come back as HTTP 200 with an error body, and the non-streaming POST /api/chat does not work yet. Use the WebSocket.
  • 알려진 결함: 세션 오류가 HTTP 200 과 오류 본문으로 돌아오고, 비스트리밍 POST /api/chat 은 아직 동작하지 않습니다. WebSocket 을 쓰세요.
