Ecosystem

생태계

Python on every platform

모든 플랫폼 위의 Python

Gemstone does not depend on these projects yet. It is the application they are built to carry.

Gemstone 은 아직 이 프로젝트들에 의존하지 않습니다. 이들이 실어 나르려고 만든 애플리케이션입니다.

python-multiplatform

CPython embedded in Kotlin Multiplatform. Gemstone's planned path to running the model inside the app.

Kotlin Multiplatform 에 임베딩한 CPython. 모델을 앱 안에서 돌리기 위한 Gemstone 의 예정 경로.

pythonx-compose

A Python wrapper for Compose Multiplatform: the UI toolkit Gemstone's client is written in.

Compose Multiplatform 의 Python 래퍼: Gemstone 클라이언트가 쓰는 UI 툴킷.

toolchain

The Gradle build plugin and tooling that package Python for Kotlin Multiplatform apps.

Kotlin Multiplatform 앱용으로 Python 을 패키징하는 Gradle 빌드 플러그인과 도구.

torchnative

The real PyTorch ecosystem, running on device rather than reimplemented.

다시 구현하지 않고 기기 위에서 그대로 도는 실제 PyTorch 생태계.

compose-graal-hello

A Compose desktop app compiled with GraalVM native-image: the reference for Gemstone's JVM-free desktop build.

GraalVM native-image 로 컴파일한 Compose 데스크톱 앱: Gemstone 의 JVM 없는 데스크톱 빌드의 참고 구현.

Gemstone itself lives in the LogitAI organisation.

Gemstone 자체는 LogitAI 조직에 있습니다.

Gemstone is Apache-2.0-licensed. Source on GitHub.

Gemstone 은 Apache-2.0 라이선스입니다. 소스는 GitHub 에 있습니다.

thisisthepy 생태계의 일부입니다.
