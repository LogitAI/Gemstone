Gemstone

One AI chat client for every platform, built to run the model on your own device.

모든 플랫폼에 하나의 AI 채팅 클라이언트, 모델은 내 기기에서.

Gemstone pairs a Compose Multiplatform client with a Python model server you run yourself — and is on its way to putting the model inside the app.

Gemstone 은 Compose Multiplatform 클라이언트와 직접 띄우는 Python 모델 서버를 짝지은 프로젝트이며, 모델을 앱 안으로 옮기는 중입니다.

The idea

생각

Most AI chat apps are a thin window onto someone else's server. Gemstone starts from the other end.

대부분의 AI 채팅 앱은 남의 서버를 들여다보는 얇은 창입니다. Gemstone 은 반대편에서 출발합니다.

Principles

원칙

01

Your model, your device

내 모델, 내 기기

Open-weight models, quantised to fit, run on hardware you control — never on someone else's account.

공개 가중치 모델을 양자화해, 내가 통제하는 하드웨어에서 돌립니다. 남의 계정 위가 아닙니다.

02

One client, every screen

하나의 클라이언트, 모든 화면

Android, iOS, desktop and web share one Kotlin codebase — the UI, the view models and the protocol.

Android, iOS, 데스크톱, 웹이 하나의 Kotlin 코드베이스 — UI, 뷰모델, 프로토콜 — 를 공유합니다.

03

Show the work

과정을 보여준다

Tokens stream as they are generated. Reasoning and tool calls are visible, not hidden behind a spinner.

토큰은 생성되는 즉시 흐릅니다. 추론과 도구 호출은 스피너 뒤에 숨지 않고 보입니다.

04

Honest about status

현황에 정직하다

Every capability is marked implemented, partial or planned — and the spec may not outgrow the intent.

모든 기능은 구현 · 부분 · 예정으로 표시됩니다. 스펙은 의도를 넘어설 수 없습니다.
