Getting started

시작하기

From clone to first answer

클론부터 첫 답변까지

Run the model server on your machine — a CPU is enough — then open any client.

내 머신에서 모델 서버를 띄우고 — CPU 면 충분합니다 — 아무 클라이언트나 엽니다.

Requirements

준비물

  • Git, Python 3.13 (the project pins >=3.13,<3.14 until torchnative is measured on 3.14) and uv.
  • Git, Python 3.13 (torchnative 가 3.14 에서 측정될 때까지 >=3.13,<3.14 로 고정), uv.
  • JDK 21 or newer for the Kotlin client.
  • Kotlin 클라이언트용 JDK 21 이상.
  • No GPU is needed: the engine runs on the CPU (GPU support is planned) and the default model, Qwen 3 0.6B, is small enough for it.
  • GPU 는 필요 없습니다. 엔진은 CPU 에서 돌고(GPU 지원은 예정) 기본 모델인 Qwen 3 0.6B 는 그걸로 충분합니다.
  • Xcode, for iOS only.
  • iOS 에만 Xcode.

1. Install the server

1. 서버 설치

git clone https://github.com/LogitAI/Gemstone.git
cd Gemstone
uv sync --extra torch

That installs upstream PyTorch. To use torchnative instead, run uv sync --extra torchnative. The two extras cannot be installed together.

이렇게 하면 upstream PyTorch 가 설치됩니다. 대신 torchnative 를 쓰려면 uv sync --extra torchnative 를 실행하세요. 두 extra 는 함께 설치할 수 없습니다.

2. Start it

2. 실행

uv run --extra torch python -m api run server                  # 127.0.0.1:23100 (loopback only)
uv run --extra torch python -m api run server 127.0.0.1 23100  # explicit host and port

uv run uses the environment uv sync created, so there is no virtual environment to activate. Use --extra torchnative if you installed that one. Logs go to the console at INFO; set GEMSTONE_LOG_LEVEL=DEBUG to also log prompts and answers.

uv run 은 uv sync 가 만든 환경을 쓰므로 가상환경을 따로 활성화할 필요가 없습니다. torchnative 를 설치했다면 --extra torchnative 를 쓰세요. 로그는 INFO 수준으로 콘솔에 나가며, GEMSTONE_LOG_LEVEL=DEBUG 를 설정하면 프롬프트와 답변도 기록합니다.

The model downloads from Hugging Face the first time a session uses it — several gigabytes, once.

모델은 세션이 처음 사용할 때 Hugging Face 에서 내려받습니다 — 수 GB, 한 번만.

3. Open a client

3. 클라이언트 열기

The quickest is the web client the server already bundles: open http://127.0.0.1:23100/. For a native window:

가장 빠른 것은 서버에 이미 들어 있는 웹 클라이언트입니다: http://127.0.0.1:23100/ 를 여세요. 네이티브 창은:

./gradlew :app:run           # desktop
./gradlew :app:installDebug  # Android

Clients look for the server at 127.0.0.1:23100. To use one on another machine, start the server with GEMSTONE_HOST=0.0.0.0 and a GEMSTONE_API_KEY (Run the server), then see Connect clients.

클라이언트는 127.0.0.1:23100 에서 서버를 찾습니다. 다른 머신의 서버를 쓰려면 GEMSTONE_HOST=0.0.0.0 과 GEMSTONE_API_KEY 로 서버를 띄운 뒤(서버 운영) 클라이언트 연결을 보세요.

If something goes wrong

문제가 생기면

  • ModuleNotFoundError from a bare python -m api run server means that is the system Python, not the synced environment — start it with uv run --extra torch as above.
  • 그냥 python -m api run server 에서 ModuleNotFoundError 가 나면 동기화된 환경이 아니라 시스템 Python 인 것입니다 — 위처럼 uv run --extra torch 로 실행하세요.
