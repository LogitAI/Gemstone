Getting started

시작하기

From clone to first answer

클론부터 첫 답변까지

Run the model server on a machine with a GPU, then open any client.

GPU 가 있는 머신에서 모델 서버를 띄우고, 아무 클라이언트나 엽니다.

Requirements

준비물

  • Git, Python 3.12 (exactly — the project pins >=3.12,<3.13) and uv.
  • Git, Python 3.12 (정확히 — 프로젝트가 >=3.12,<3.13 으로 고정), uv.
  • JDK 21 or newer for the Kotlin client.
  • Kotlin 클라이언트용 JDK 21 이상.
  • An NVIDIA GPU is recommended for Qwen 3 14B. The CPU works, slowly.
  • Qwen 3 14B 에는 NVIDIA GPU 를 권장합니다. CPU 로도 되지만 느립니다.
  • Xcode, for iOS only.
  • iOS 에만 Xcode.

1. Install the server

1. 서버 설치

git clone https://github.com/LogitAI/Gemstone.git
cd Gemstone
uv sync

Want llama.cpp on CUDA? Rebuild it with GPU support:

llama.cpp 를 CUDA 로 돌리려면 GPU 지원으로 다시 빌드합니다:

CMAKE_ARGS="-DGGML_CUDA=on -DLLAVA_BUILD=off -DCMAKE_CUDA_ARCHITECTURES=native" \
FORCE_CMAKE=1 uv pip install llama-cpp-python --no-cache-dir --force-reinstall --upgrade

2. Start it

2. 실행

python -m api run server                  # 0.0.0.0:23100
python -m api run server 127.0.0.1 23100  # explicit host and port

The model downloads from Hugging Face the first time a session uses it — several gigabytes, once.

모델은 세션이 처음 사용할 때 Hugging Face 에서 내려받습니다 — 수 GB, 한 번만.

3. Open a client

3. 클라이언트 열기

The quickest is the web client the server already bundles: open http://127.0.0.1:23100/. For a native window:

가장 빠른 것은 서버에 이미 들어 있는 웹 클라이언트입니다: http://127.0.0.1:23100/ 를 여세요. 네이티브 창은:

./gradlew :app:run           # desktop
./gradlew :app:installDebug  # Android

Clients look for the server at 127.0.0.1:23100. To use one on another machine, see Connect clients.

클라이언트는 127.0.0.1:23100 에서 서버를 찾습니다. 다른 머신의 서버를 쓰려면 클라이언트 연결을 보세요.

If something goes wrong

문제가 생기면

  • python -m api without run server crashes with IndexError — always pass both words.
  • run server 없이 python -m api 를 실행하면 IndexError 로 죽습니다 — 두 단어를 꼭 넘기세요.
  • “transformers module is not installed” or “llama_cpp module is not installed” is a warning: that backend is disabled, the other still works.
  • “transformers module is not installed” 나 “llama_cpp module is not installed” 는 경고입니다. 그 백엔드만 꺼지고 다른 쪽은 동작합니다.
  • The model failed to load on GPU? The GGUF backend retries with fewer GPU layers automatically, down to CPU only.
  • GPU 로드에 실패했나요? GGUF 백엔드는 GPU 레이어 수를 줄여가며 CPU 전용까지 자동으로 재시도합니다.
