Run and configure the server

서버 실행과 설정

Choose a model and a backend, set keys, and size it to your GPU.

모델과 백엔드를 고르고, 키를 설정하고, GPU 에 맞춥니다.

Host and port

호스트와 포트

python -m api run server [host] [port]   # defaults: 0.0.0.0 23100

The server reloads on code changes and keeps WebSockets alive for 300 seconds of silence — long enough for a slow first token.

서버는 코드가 바뀌면 다시 로드되고, WebSocket 을 300초 침묵까지 유지합니다 — 느린 첫 토큰에도 충분합니다.

A backend whose library is missing is replaced by a placeholder and a warning is printed, so the server still starts.

라이브러리가 없는 백엔드는 자리표시자로 바뀌고 경고만 출력되므로, 서버는 그래도 뜹니다.

Keys

키

Web search uses SerpApi when a key is present and falls back to scraping Bing otherwise. Put the key in a .env file at the repository root (never commit it):

웹 검색은 키가 있으면 SerpApi 를, 없으면 Bing 스크래핑을 씁니다. 키는 저장소 루트의 .env 파일에 둡니다 (절대 커밋하지 마세요):

cp .env.example .env
# .env
SERPAPI_KEY=<your key>

Weather, holidays and exchange rates use free public APIs that need no key — but they do send your query over the internet.

날씨, 공휴일, 환율은 키가 필요 없는 무료 공개 API 를 씁니다 — 다만 질의가 인터넷으로 나갑니다.
